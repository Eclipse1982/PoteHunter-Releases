# PoteHunter downloads

This is the public, binary-only distribution for PoteHunter. Application source code remains in the private [PoteHunter source repository](https://github.com/Eclipse1982/PoteHunter).

Download the latest stable [Windows release](https://github.com/Eclipse1982/PoteHunter-Releases/releases/latest). Each release provides a per-user Windows installer, a standalone self-contained EXE, and a ZIP with verification reports. SHA-256 sidecars are included for binary downloads.

PoteHunter can check this public release channel from **Options > Updates**. It verifies the executable checksum and packaged self-test before updating.
